## 已确认口径（产品拍板，不可推翻）

1. **免确认模式（notifyMode=1）**：平台侧自动代成员确认后下发，`confirmedBy=system`。
2. **自动标签**：任务收敛为 FINISHED 后，只对**实际发送成功**的对象打标；失败对象不打。
   打标失败不改变任务 FINISHED 状态，记 Warn 并可随下一轮轮询重试。
3. **双重范围**：应用可见范围 ∩ 客户联系使用范围。范围外账号**过滤后继续**，
   在创建点击「确定」时弹窗展示被过滤账号与剩余触达范围。
4. **定时任务人数**：待执行期间展示**创建时预估人数**，下发后展示实际目标数。
   两者分开存储，不能把未解析的 0 当作预估 0 展示。
5. **取消/删除后不可确认**：`canConfirm=false` 并给出原因；
   不能用「详情 404」判断，小组视角下正常任务也可能 404。
